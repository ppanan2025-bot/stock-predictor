# context/: generated per-company context (loaded when working in context/)

- `context/companies/<TICKER>.md` is GENERATED by `npm run context -- --ticker <T>` (skill `/company-context`) from stockdb as
  `stock_ro`: profile, latest deterministic features from verified closes, top verified research notes (`N<id>`, `[S<id>]`),
  recent verified news, last predictions with outcomes. Never edit it (the protected-files hook blocks writes); regenerate.
- Read only the ticker in focus. Quote ids, not page text; numbers shown are pack/DB values, so they are traceable.
- `STALE` or `not stored yet` features: the shown values are recomputed from verified closes; `compute_features` stores them.
- Null features mean insufficient verified history (SPCX: `short_history`): never fill them in. Inbox leads never appear here.
