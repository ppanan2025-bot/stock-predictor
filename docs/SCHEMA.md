# stockdb schema

MySQL 8.4, database `stockdb`, dev 127.0.0.1:3310 (compose project `stock-predictor`), throwaway test DB 127.0.0.1:3320
(tmpfs, `report_host=sp-test-db`). Source of truth: `db/init/` (runs once on a fresh volume); existing databases get every
change idempotently from `npm run db:migrate` (tables, added columns, widened enums, triggers, views, grants, NYSE closures;
it exits 1 if any data row count changes). Table sections below are generated from `db/init/01-schema.sql`.

Conventions: all timestamps UTC `DATETIME(3)` (server `--default-time-zone=+00:00`); money `DECIMAL(14,4)`; months `CHAR(7)`
`YYYY-MM`; returns are simple returns as `DECIMAL(10,6)` unless noted.

| File | Content |
|---|---|
| `01-schema.sql` | 19 tables (below) |
| `02-users.sh` | users and grants |
| `03-triggers.sql` | BEFORE INSERT/UPDATE guards |
| `04-seed.sql` | companies GOOGL, AMZN, AAPL, SPCX (mirrors `config/companies.json`) |

| `06-closures.sql` | NYSE full-day closures 2023-2027 (generated by `scripts/gen-closures.mjs`) |

## Users and grants (`02-users.sh`)

| User | Grants | Used by |
|---|---|---|
| `root` | all | `npm run db:migrate` only (password in `.env`, never read by Claude) |
| `stock_app` | SELECT, INSERT on all tables; UPDATE only on the columns below; DELETE only on `quant_features` (REPLACE) | MCP write tools |
| `stock_ro` | SELECT | MCP read tools, `run_readonly_sql` (READ ONLY session, 10 s), hooks, `npm run audit/validate/context/baseline/backtest/run-status` |

`stock_app` column UPDATE grants:
- `sources`: verification_status, verification_reason, last_checked_at, title_fetched, published_at_fetched, http_status, fetched_at, content_sha256, text_len, wire_agency
- `news_items`: status, reason, corroboration_count, corroborating_source_ids, sentiment
- `predictions`: status, final_confidence, finalized_at, report_sha256
- `runs`: status, started_at, finished_at, plan
- `agent_tasks`: status, started_at, finished_at, output_ref, error
- `analyses`: prediction_id, status, review_issues, review_summary, reviewed_at

Every other column is immutable for the app user; no table except `quant_features` can lose rows.

## Triggers (`03-triggers.sql`)

| Trigger | Table / event | Refuses |
|---|---|---|
| `trg_sub_bi` | price_submissions BI | verified without reason ok, a positive close and a trade date inside the month; reason ok on a non-verified row |
| `trg_price_bi` | month_end_prices BI | no matching verified submission (same ticker/month/date/close); close != Nasdaq close; abs_diff != \|A-B\| or > 0.0100; source URLs not the Nasdaq historical / CNBC bars endpoints; trade_date != last NYSE trading day (weekends + `nyse_closures`, fails closed without a calendar for the year); fetched before 21:00 UTC on trade_date or in the future |
| `trg_note_bi` | research_notes BI | verified note without excerpt_found=1, 40-1200 chars, `excerpt_sha256 = SHA2(excerpt)` and a verified/corroborated source |
| `trg_news_bi`, `trg_news_bu` | news_items BI/BU | verified/corroborated without a verified/corroborated source with content_sha256; corroborated with count < 2 |
| `trg_cit_bi` | prediction_citations BI | citing a source that is not verified/corroborated |
| `trg_pred_bi` | predictions BI | not inserted as draft; target != as_of + 1; no verified close for (ticker, as_of); not low <= mid <= high; p_up outside [0,1]; \|overlay_p_adj\| > 0.15 |
| `trg_pred_bu` | predictions BU | reviving a withdrawn row; changing a final row (except withdrawal); re-hashing a reviewed/final report; reviewed without a review on the current sha; final without report_sha256, a validator pass on it, >= 3 accepted analyses linked (and none not accepted), every citation still verified and the as-of close |
| `trg_rev_bi` | reviews BI | `stale_review`: report_sha256 != the draft/reviewed prediction's current sha |
| `trg_out_bi` | prediction_outcomes BI | actual close/date != the verified close of the target month |
| `trg_an_bi` | analyses BI | not matching its run (target month, ticker in runs.tickers); not inserted as submitted; any evidence id not a verified/corroborated source |
| `trg_an_bu` | analyses BU | re-opening an accepted/rejected verdict; accepting without reviewed_at or with evidence no longer verified |
| `trg_closure_bi` | nyse_closures BI | any user but root (a closure would move a month-end) |

Pinned constants: price tolerance 0.0100 (= `config/verification.json` price.tolerance_abs) and 3 accepted analyses
(= `config/model.json` consensus.min_accepted_analyses). Loosening either needs a reviewed migration.

## Views (`05-views.sql`, SQL SECURITY INVOKER)

- `v_usable_sources`: sources with status verified/corroborated and a content_sha256.
- `v_latest_prediction`: the highest non-withdrawn version per (ticker, target_month).
- `v_calibration`: per ticker and `ALL` (rollup) over reviewed/final scored predictions: n_scored, hit_rate, mean_brier,
  range_coverage, mean_abs_error.
